# نشر قواعد خصوصية Firestore

يستخدم التطبيق قاعدة Firestore المسماة:

- المشروع: `tidy-filament-zxq1s`
- قاعدة البيانات: `ai-studio-5b60aa9f-658d-49f6-bc51-1d2f57117aaa`

تم تعطيل القراءة والكتابة على مجموعة `users/{userId}/diagnoses` لأن نتائج التشخيص أصبحت مؤقتة ولا تُحفظ كسجل للمزارع.

بعد دمج التحديث في فرع `codex/free-render-preview`، يحاول سير العمل `Deploy Firestore privacy rules` نشر ملف `firestore.rules` إلى قاعدة البيانات المحددة.

لتمكين النشر الآلي، أضف سر GitHub باسم `FIREBASE_SERVICE_ACCOUNT_JSON` يحتوي بيانات حساب خدمة لديه صلاحية إدارة قواعد Firebase Security Rules في المشروع. لا تضع بيانات الحساب داخل المستودع أو داخل ملفات التطبيق.

إذا لم يكن السر موجوداً، سيتخطى سير العمل النشر دون تغيير قواعد Firebase الحالية. تحقق من نجاح سير العمل قبل اعتبار قواعد منع السجلات القديمة مفعّلة على الإصدارات السابقة.
